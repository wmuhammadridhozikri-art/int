Kelola Image Slider

Tambah banyak foto sekaligus, ubah judul/deskripsi/tombol, atur urutan, ganti atau hapus. Foto dioptimalkan otomatis (maks. 1920 px, WebP). Setelah selesai, unduh paket ZIP lalu salin isinya ke folder proyek.

Klik untuk memilih foto atau seret beberapa foto ke sini
Format: JPG, JPEG, PNG, WEBP

    Cara menerapkan perubahan

    1. Klik Unduh Paket ZIP.
    2. Ekstrak ZIP, lalu salin folder assets ke folder proyek website (timpa assets/slider/slides.js).
    3. Upload ulang ke hosting. Slider di halaman utama langsung memakai data baru.

    Foto lama yang dihapus/diganti tidak ikut terhapus otomatis dari folder assets/slider/; hapus manual jika ingin menghemat ruang. Buka halaman ini dari website yang sudah berjalan (satu folder dengan index.html) agar slide yang sudah ada ikut termuat.
